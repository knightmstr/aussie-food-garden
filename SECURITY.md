# Security

This repository is a static guide and a small offline web app. It has no server, no accounts and no user data.

- The app sets a strict Content Security Policy and loads only its own files. The markdown library in `site/vendor/` is bundled, not loaded from a CDN.
- To report a security problem in the code, use GitHub's **Security → Report a vulnerability** on this repository.
- For wrong or unsafe gardening information (for example a toxic plant or a spray), open a *Correction or better source* issue and mark it as a safety issue.
