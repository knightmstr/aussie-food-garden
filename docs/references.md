# References

Every source this guide cites, in one place. A number in square brackets on a crop page, like [12], opens its entry here. Each entry shows the title, the kind of source, and where this guide uses it. The kind of each source is this guide's own label, not the publisher's. Government sources are not automatically current, so check the year on the page you open.

Evidence labels and gaps are on the page that uses each source. This list only says where a source comes from.
